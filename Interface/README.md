# Visitor App

Flutter application for visitors. Run Flutter commands from this directory.

- `lib/main.dart`: application entry point.
- `lib/core/`: shared configuration, API, and local storage.
- `lib/features/`: visitor-facing features such as authentication, heritage sites, artifacts, beacons, favorites, visit history, and feedback.
- `lib/shared/`: reusable UI and utilities.
- `android/`, `web/`, and `test/`: platform configuration and tests.

The feature directories are structural placeholders until their implementations are added.
