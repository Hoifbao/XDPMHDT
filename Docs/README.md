# Project Documentation

- `requirements/`: user and software requirements (URS/SRS).
- `api/`: REST API specification, such as OpenAPI/Swagger.
- `database/`: schema and database design notes; diagrams remain in `../Diagram/ERD/`.
- `testing/`: test plans and test reports.
- `deployment/`: environment setup and deployment instructions.
- `user-manual/`: visitor app and administrator user guides.

System diagrams are kept in the existing top-level `Diagram/` folder.
